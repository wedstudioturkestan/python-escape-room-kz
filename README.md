# Python Escape Room — CODE RED (тексерілген нұсқа)

5 кезең, 15 тексерілген Python сұрағы, 10 минут. Интерфейс қазақша.

## Ереже

Әр кезеңде 3 сұрақ бар. Дұрыс жауап берілсе де, қате жауап берілсе де келесі сұраққа өтеді. 3 сұрақтың 2 не 3-еуі дұрыс болса, кезең ашылады. 0 не 1 дұрыс болса, осы кезең қайта басталады (таймер тоқтамайды). Дұрыс жауап +10 ұпай; кеңес −3 ұпай (сәтті аяқталған кезеңнің соңғы талпынысында ғана). Қате жауап +0.

## GitHub Pages-та жариялау

1. Public GitHub репозиторийін ашыңыз.
2. `index.html` файлын репозиторийдің негізгі бумасына қосыңыз.
3. GitHub-та **Settings → Pages → Build and deployment → Deploy from a branch** таңдап, `main` және `/(root)` көрсетіңіз.
4. Save басып, жарияланған мекенжайды GitHub-тағы Pages бөлімінен қараңыз.

Ойынға қосымша сервер не Python орнату қажет емес. Google Sheets нәтижелерді автоматты алуы үшін `index.html` ішіндегі `RESULTS_URL` бөлек бапталуы тиіс. Бапталмаса, нәтижені жергілікті браузерде көруге және CSV-ға жүктеуге болады. Жеке деректерді ашық GitHub репозиторийіне жүктемеңіз.
